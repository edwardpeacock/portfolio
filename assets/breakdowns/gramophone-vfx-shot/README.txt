Breakdown images for: gramophone-vfx-shot

Drop your images in this folder using these names (.jpg, .png or .webp):

  01-original-plate   ->  Original plate
  02-camera-track   ->  Camera track
  03-3d-gramophone   ->  3D gramophone
  04-reflections   ->  Reflections
  05-glass-refraction   ->  Glass refraction
  06-final-composite   ->  Final composite

How it works:
- Each image is the FULL shot with one more element added, so 01 is the clean starting image and the last one is the finished composite.
- Use the same size and 16:9 shape for every image in this folder (for example 1920x1080).
- As the visitor scrolls, each image wipes in over the one before it.
- To rename, reorder or add steps, edit the breakdown list for this project in data/site.js.
